# ENFIESTATE Caquetá

Página web de una sola página de ENFIESTATE: recreación, animación, shows y decoración para eventos
en Florencia y todo el Caquetá. Es un sitio estático (HTML, CSS y JavaScript sin librerías), sin
servidor ni paso de compilación.

## Estructura

- `index.html`: todo el contenido de la página.
- `css/estilos.css`: estilos, animaciones y versiones para celular y tablet.
- `js/app.js`: banderines, globos, confeti, menú, galería con filtros, visor de fotos y enlaces de WhatsApp.
- `img/fotos/`: fotos de eventos reales (WebP).
- `img/flyers/`: flyers de planes, decoración, traje de Santa y publicidad (WebP).
- `img/logo.webp`, `img/logo-sm.webp`, `img/favicon.png`: logo e icono.
- `share.jpg`: imagen que se ve al compartir el enlace en redes y WhatsApp.

Abre una terminal en esta carpeta y corre `python3 -m http.server 8000`; luego entra a
http://localhost:8000.
